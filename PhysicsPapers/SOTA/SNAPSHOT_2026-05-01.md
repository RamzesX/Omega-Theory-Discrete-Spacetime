## 6. KEY RESEARCH FINDINGS THIS SPRINT

### Cypher-first principle
Per-Theorem feature extraction (difficulty, tactic_evidence, freshness) via Cypher
migration over `proof_body` is **100× faster** than rebuilding Lean + reloading
declarations. Validated on 385K Theorems in seconds vs hours.

### Neo4j RAM right-sizing
Live measurement contradicts the original plan's 100G heap recommendation.
Real working set: ~18.8 GB. Recommended: 16G heap + 24G pagecache = 40G total
(currently allocated 88G; using 21%).

### 2026 cron landscape
- Cloud Routines launched 2026-04-14 (24/7 persistent agent loops)
- 72-hour hard cap on `/loop` runs forces human review
- Cache TTL silently dropped 1h → 5min in 2026-03 → 20-60% cost spike
- Mitigation: explicit `cache_control: {ttl: "1h"}` on stable prefix

### 5 anti-pause failure modes
For long-running cron loops, these 5 patterns reliably break:
1. Narrative collapse → IDENTITY ANCHOR (Erdős Primarch BOOK_I)
2. Cache TTL regression → explicit 1h cache_control
3. Stuck without progress → 3-strike rule (no commits in 6h × 3 fires)
4. Idle drift → trigger guard (skip if phase=idle + no OPEN)
5. Token cost runaway → end-fire criteria (≥1 commit OR Block transition)

### Project speedup estimate
With ALL infra: ~2.5-3× wall-clock project completion (~7 months → ~2.5 months).
Per-target: T-5 3-5×, T-9 HD axiom 2-4×, SM precision 2.3×, Tier-99 routine 3-6×.
